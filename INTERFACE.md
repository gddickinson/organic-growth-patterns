## Key Classes

- **`OrganicPatternBase`** (`pattern_base.py`): ABC defining `seed_random()`, `seed_center()`, `grow()`.
- **`OrganicPatternGenerator`** (`organic_patterns.py`): 2D implementation. Methods: `seed_random()`, `seed_center()`, `seed_line()`, `grow()`, `add_environment()`, `visualize()`.
- **`OrganicPattern3D`** (`organic_patterns_3d.py`): 3D implementation. Methods: `seed_random()`, `seed_center()`, `grow()` (counts neighbours with the kernel's support), `active_coords()` (x, y, z of live cells), `visualize_3d()`, `create_timelapse()`.

## Data Flow

1. Create a generator instance with grid dimensions
2. Seed the grid (`seed_random`, `seed_center`, `seed_line`)
3. Call `grow(pattern_type)` repeatedly to simulate
4. Optionally `add_environment()` (2D only)
5. `visualize()` / `visualize_3d()` to render output

## Pattern Registries

- `PATTERN_REGISTRY_2D`: coral, lichen, mycelium (2D kernels + color maps)
- `PATTERN_REGISTRY_3D`: coral, mycelium, crystal (3D kernels + color lists)

## Web interface (`web/`)

| File | Purpose |
|------|---------|
| `web/app.py` | FastAPI app. GET `/api/info`, `/api/patterns`, `/api/colormaps` (listed in `STATIC_ENDPOINTS`, exported to JSON for the static site); POST `/api/simulate2d`, `/api/simulate3d` |
| `web/simulate.py` | `replay_2d()` / `replay_3d()`: run an action list (`seed_random`, `seed_center`, `seed_line`, `grow`, `env`) through the real generators after `np.random.seed`; `patterns_payload()`, `colormaps_payload()` |
| `web/static/index.html`, `style.css` (shared kit), `style_app.css`, `core.js` (shared kit: router, `api()`) | Page shell |
| `web/static/main.js`, `static_api.js`, `bg.js` | Entry point, static-site data layer, animated background |
| `web/static/mt19937.js` | `RandomState`: numpy-compatible `seed`, `random()` (random_sample), `choiceBinary()` (np.random.choice) |
| `web/static/growth_engine.js` | `Generator2D` (port of `OrganicPatternGenerator`), `convolveWrap2d`, `replay2d`, `displayIndices` (visualize()'s mapping) |
| `web/static/growth3d_engine.js` | `Generator3D` (port of `OrganicPattern3D`), `convolveWrap3d`, `replay3d` |
| `web/static/growth_engine.test.mjs` | Node test against `tests/fixtures/growth_fixture.json` |
| `web/static/render.js` | 2D canvas via colour LUT, 3D scatter projection, sparkline, PNG export |
| `web/static/lab_common.js` | Action log, Python-code generator, "Check with Python" panel, small UI helpers |
| `web/static/home.js`, `grow.js`, `grow3d.js`, `rules.js`, `about.js` | Pages `#/`, `#/grow`, `#/grow3d`, `#/rules`, `#/about` |

Rules and colours are never duplicated in JS: the pages load them from `/api/patterns` and `/api/colormaps`, which read
`pattern_base.py` and matplotlib.
